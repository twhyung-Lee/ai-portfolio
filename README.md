# AI Convergence Portfolio

정적 포트폴리오 웹사이트입니다. `index.html`을 브라우저로 열면 확인할 수 있습니다.

## Git 시작하기

Git을 설치한 뒤 이 폴더에서 아래 명령을 실행하세요.

```powershell
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
```

GitHub 원격 저장소를 만든 경우:

```powershell
git remote add origin <YOUR_GITHUB_REPOSITORY_URL>
git push -u origin main
```

공개하기 전 `index.html`의 `your.email@example.com`을 본인의 이메일 주소로 바꾸세요.
